# 기획서 v2 — Aside AI 브라우저

제목:          검색은 AI가, 나는 고르기만! AI 브라우저 Aside 설치부터 활용까지
대상:          40~60대 AI에 관심 많은 시니어 — 챗GPT는 써봤지만 "AI가 직접 인터넷을 해준다"는 건 처음인 분
길이/형식:     16:9 가로, 약 4분, 컴퓨터 화면 실습
시청자 고민:   식당 하나 고르려 해도 블로그 10개 열고, 비교하고, 메모하느라 30분이 간다
해결 약속:     이 영상을 보면 Aside를 설치하고, 오늘 바로 "찾고 비교하는 일"을 AI에게 맡길 수 있다

## 스토리
| 구간 | 시간 | 내용 |
|---|---|---|
| ① 훅 | 0:00~0:15 | **결과부터**: 한 문장 부탁 → AI가 혼자 여러 사이트를 돌고 → 식당 비교표 완성 (빨리감기). "이걸 제가 안 하고, AI가 했습니다." |
| ② 공감 | ~0:35 | "식당 하나, 여행지 하나 고르는데 창 10개 열고 복사·붙여넣기… 저만 그런가요?" |
| ③ 약속 | ~0:45 | "오늘 5분이면 설치하고, 이 심부름 3가지를 바로 시켜볼 수 있습니다." |
| ④ 준비 | ~1:30 | 설치 빠르게: 홈페이지 → 내려받기 → 설치 → 로그인 (화면 빠르게, 요점만 자막) |
| ⑤ 실전 | ~3:20 | 심부름 3개 (쉬운 것 → 놀라운 것) ↓ |
| ⑥ 안심 | ~3:45 | AI가 **결제·예약 직전에 멈추고 물어보는 화면** 보여주기 + "비밀번호는 AI가 보지 않습니다" |
| ⑦ 마무리 | ~4:00 | 숙제: "이번 주말 가족 외식 장소, AI에게 맡겨 보세요" + 다음 영상 예고 |

## 실전 예시 (⑤)
1. **쉬운 것** — "오늘 경제 뉴스 3개만 쉽게 요약해줘" → 읽기만 해도 되는 AI
2. **쓸모 있는 것** — "강남역 근처, 부모님 모시고 갈 한정식집 4인 룸 있는 곳 3곳, 가격·주차 비교표로" → 여러 사이트를 돌며 비교 ⭐ 훅에도 사용
3. **놀라운 것** — "다음 주 토요일 오전 서울→부산 기차 시간 찾아서 예매 직전까지 해줘" → 내 계정으로 직접 움직이고, 결제 전에 멈춤 (= ⑥ 안심과 연결)

마무리 한마디: 검색은 AI에게, 결정은 내가.
썸네일 문구:   검색 끝! AI가 해줌
