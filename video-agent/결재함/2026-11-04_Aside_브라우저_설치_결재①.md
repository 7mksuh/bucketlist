# 기획서 — Aside AI 브라우저 설치하고 처음 써보기

제목:          AI가 대신 인터넷 해주는 브라우저, 5분 만에 설치하기
대상:          크롬·네이버로 검색은 하지만 AI 브라우저는 처음인 60~70대
길이/형식:     16:9 가로, 2~3분, **컴퓨터 화면** 실습
시청자 고민:   "AI 브라우저가 좋다는데, 뭘 깔아야 하고 어떻게 쓰는지 모르겠다"
해결 약속:     이 영상을 보면 Aside를 설치하고 AI에게 첫 심부름을 시켜볼 수 있다
핵심 단계:     1. 홈페이지에서 내려받기
               2. 설치 파일 열어 설치하기
               3. 가입·로그인하기
               4. AI에게 첫 심부름 시키기 (예: "서울 내일 날씨 알려줘")
주의 한마디:   결제·송금·글 올리기는 AI가 묻는 화면에서 **꼭 내 눈으로 확인 후** 누르기
마무리 한마디: 이제 검색창 대신 AI 비서에게 말로 부탁해 보세요
썸네일 문구:   AI가 대신 검색!

## 촬영 요청 (캡틴)
- 컴퓨터 화면 **녹화 권장** (윈도우: 캡처 도구 `Win+Shift+S` → 녹화 버튼, 맥: `Cmd+Shift+5`)
- 또는 단계별 캡처 6~8장: 다운로드 버튼 / 설치 창 / 설치 완료 / 로그인 화면 / 첫 화면 / 질문 입력 / AI 답변 / 확인 요청 화면(있으면)
- 촬영 전 확인: ① 윈도우판이 공식 페이지에 있는지 ② 무료로 쓸 수 있는 범위 ③ 한국어로 질문해도 되는지
- 개인정보(이메일, 비밀번호 저장 팝업) 화면은 촬영 후 알려주시면 가림 처리
