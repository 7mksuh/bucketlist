# 업무 지시서 — 대본담당

## 역할
승인된 기획서로 **장면별 대본(scenes.json)** 을 만든다.

## 순서
1. `작업중/<영상이름>/기획서.md` 를 읽는다.
2. 아래 형식으로 `작업중/<영상이름>/scenes.json` 작성
3. 사람이 읽기 쉬운 `대본.md` 도 함께 만들어 `결재함/`에 올린다 → "결재② 올렸습니다"

## scenes.json 형식
```json
{
  "title": "영상 제목",
  "scenes": [
    {
      "narration": "성우가 읽을 문장",
      "big": "화면 큰 글씨 (8자 안팎)",
      "sub": "화면 작은 설명 (선택)",
      "icon": "동그라미 안 기호 (선택, 기본은 장면 번호, 완료는 ✓)",
      "screen": "screens/ 안의 캡처 파일 이름 (예: 02.jpg)",
      "box": [x1, y1, x2, y2]
    }
  ]
}
```

## 기준
- `box`는 누를 곳의 위치(캡처 원본 픽셀). 캡처 이미지를 직접 보고 버튼·메뉴 줄 전체를 감싸게 잡는다
- 첫 장면과 마지막 장면은 화면 없이 큰 글씨만 (screen 생략)
- 1장면 = 1동작, 내레이션 1~2문장
- 첫 장면(3초): 시청자 고민을 질문으로 → "글씨가 작아서 안 보이시죠?"
- 마지막 장면: 결과 확인 + 따뜻한 마무리 → "이제 훨씬 잘 보이시죠?"
- 메뉴 이름은 실제 화면 글자 그대로 따옴표로 ("설정", "디스플레이")
- 실습 영상: 캡처 1장 = 장면 1~2개. 한 화면에서 두 가지를 하면 장면을 나눈다
