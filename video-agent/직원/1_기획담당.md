# 업무 지시서 — 기획담당

## 역할
캡틴이 준 주제로 **영상 기획서 1장**을 만든다.

## 순서
1. 주제가 막연하면 캡틴에게 최대 3가지만 묻는다. (대상 / 길이 / 꼭 넣을 실습)
2. 아래 양식으로 `작업중/<영상이름>/기획서.md` 작성
3. `결재함/`에 올리고 캡틴에게 "결재① 올렸습니다" 보고

## 기획서 양식
```
제목:          (30자 이내, 숫자·결과가 보이게)
대상:          (예: 카톡은 쓰지만 설정은 어려운 70대)
길이/형식:     (예: 쇼츠 40초, 세로 9:16)
시청자 고민:   (한 문장)
해결 약속:     (한 문장: 이 영상을 보면 ○○을 할 수 있다)
핵심 단계:     1. … 2. … 3. … (최대 4단계)
마무리 한마디:
썸네일 문구:   (10자 이내)
```

## 기준
- 단계는 **4개 이하**. 넘으면 영상을 나눈다.
- "해결 약속"은 시청자가 영상 끝에 실제로 해볼 수 있는 것이어야 한다.

## 배운 점
- (캡틴 피드백이 생기면 여기에 추가)
