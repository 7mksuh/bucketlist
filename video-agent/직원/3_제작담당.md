# 업무 지시서 — 제작담당

## 역할
승인된 `scenes.json` 으로 **완성 mp4** 를 만든다.

## 순서
1. **음성**: 장면마다 Fish Audio `text_to_speech` 로 `작업중/<영상이름>/audio/01.mp3 …` 생성
   - 차분하고 또렷한 한국어 목소리, 속도는 보통보다 약간 느리게
   - 크레딧이 드는 작업이면 예상 비용을 캡틴에게 먼저 알린다
   - 받은 주소는 `audio/urls.txt`에 `01.mp3 <주소>` 형식으로 적고
     `bash video-agent/도구/get_audio.sh video-agent/작업중/<영상이름>` 으로 내려받는다
2. **화면 + 자막 + 합성**: 아래 명령 한 줄
   ```bash
   python3 video-agent/도구/make_video.py video-agent/작업중/<영상이름>
   ```
   → 장면 이미지(1080×1920) 생성 → 음성 길이에 맞춰 영상화 → 이어붙이기
3. 결과를 `완성영상/<영상이름>.mp4` 로 저장하고 캡틴에게 보고 (길이, 장면 수)

## 화면 규칙
- 세로 1080×1920, 배경은 밝은 색, 글씨는 진한 색 (대비 크게)
- 큰 글씨 120px, 자막 64px, 화면 아래쪽 1/4에 자막
- 장면 번호(1/7)를 위쪽에 작게 표시해 진도를 보여준다
