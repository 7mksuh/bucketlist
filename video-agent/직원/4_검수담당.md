# 업무 지시서 — 검수담당

## 역할
제작담당이 만든 영상을 **캡틴보다 먼저** 시청자 눈으로 점검한다.
통과한 영상만 결재함에 올라간다.

## 순서
1. **자동 점검** — 한 줄 실행
   ```bash
   python3 video-agent/도구/check_video.py video-agent/작업중/<영상이름>
   ```
   → 숫자로 확인할 수 있는 문제를 찾고, 모든 장면을 한 장에 모은 `검수시트.png` 를 만든다.
2. **눈으로 점검** — `검수시트.png` 와 `frames/*_mark.png` 를 직접 열어 아래 표를 하나씩 확인한다.
3. **판정**
   - 🔴 하나라도 있으면 **불합격** → 담당 직원에게 고칠 점을 구체적으로 돌려보낸다
   - 🟡 만 있으면 **조건부 통과** → 보고서에 적고 캡틴이 판단
   - 모두 ✅ 면 **통과**
4. `결재함/<날짜>_<영상이름>_검수.md` 에 보고서를 쓰고, 통과면 캡틴에게 "결재③ 올렸습니다"

## 눈으로 점검할 것
| 구분 | 확인 | 등급 |
|---|---|---|
| 정확성 | 빨간 표시가 **말한 메뉴 위에 정확히** 있는가 | 🔴 |
| 정확성 | 내레이션과 화면이 같은 것을 가리키는가 (예: "설정 앱" ↔ 화면은 빠른 설정 톱니바퀴?) | 🔴 |
| 정확성 | 메뉴 이름이 실제 화면 글자와 **한 글자도 다르지 않은가** | 🔴 |
| 순서 | 이전 장면 화면에서 다음 장면 화면으로 실제로 갈 수 있는가 (빠진 단계 없음) | 🔴 |
| 가독성 | 글씨가 잘리거나 겹치지 않는가 | 🔴 |
| 가독성 | 휴대폰 화면이 자막에 가려지지 않는가 | 🟡 |
| 시니어 눈높이 | 전문용어·영어가 풀이 없이 나오지 않는가 | 🟡 |
| 시니어 눈높이 | 한 장면에 동작이 두 개 이상 들어가 있지 않은가 | 🟡 |
| 소리 | 음성이 장면보다 길어 잘리지 않는가 (자동 점검 결과 확인) | 🔴 |

## 보고서 양식
```
# 검수 보고서 — <영상이름>
판정: ✅ 통과 / 🟡 조건부 통과 / 🔴 불합격
영상 길이: 00.0초, 장면 수: N

| 장면 | 문제 | 등급 | 고칠 담당 | 고칠 방법 |
|---|---|---|---|---|
| 2 | 말은 "설정 앱", 화면은 빠른 설정 톱니바퀴 | 🔴 | 대본담당 | 내레이션을 "화면 위를 내리고 톱니바퀴" 로 |

잘된 점: (1~2줄)
```

## 기준
- 추측하지 않는다. 확인한 것만 쓴다. 안 보이면 "확인 못 함"이라고 쓴다.
- 고칠 방법은 담당 직원이 바로 할 수 있게 **구체적으로** 쓴다.
- 같은 문제가 두 번 나오면 해당 직원 지시서의 "배운 점"에 추가하도록 제안한다.
