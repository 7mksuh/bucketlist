# 기획서 — 갤럭시 글씨 크게 하기

제목:          갤럭시 글씨, 3번만 누르면 커집니다
대상:          글씨가 작아 안경을 찾게 되는 60~70대 갤럭시 사용자
길이/형식:     쇼츠 40초 안팎, 세로 9:16
시청자 고민:   휴대폰 글씨가 작아서 문자 읽기가 힘들다
해결 약속:     이 영상을 보면 설정에서 글씨 크기를 직접 키울 수 있다
핵심 단계:     1. "설정" 열기  2. "디스플레이"  3. "글자 크기와 스타일"  4. 막대를 오른쪽으로
마무리 한마디: 이제 안경 없이도 문자가 술술 읽히실 거예요
썸네일 문구:   글씨 2배로!
