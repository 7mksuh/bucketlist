# 기획서 v3 (결재① 최종) — Aside AI 브라우저

제목:          PPT 수정도, 쿠팡 주문도 AI가! AI 브라우저 Aside 설치부터 활용까지
대상:          40~60대 AI에 관심 많은 시니어 — 챗GPT·제미나이는 써봤지만 "AI가 직접 인터넷을 해준다"는 건 처음인 분
길이/형식:     16:9 가로, 약 4~5분, 컴퓨터 화면 실습
시청자 고민:   "AI 브라우저가 뭔지, 로그인도 안 했는데 어떻게 사이트를 돌아다닌다는 건지" 감이 안 온다
해결 약속:     이 영상을 보면 AI 브라우저의 원리를 이해하고, Aside를 설치해 쇼핑과 PPT 수정을 직접 맡길 수 있다

## 스토리
| 구간 | 시간 | 내용 | 근거 |
|---|---|---|---|
| ① 훅 | 0:00~0:15 | **결과부터**: 수정이 안 되던 제미나이 노트북 슬라이드가 → 고칠 수 있는 PPT 파일로 바뀌어 열리는 장면. "제가 이거 보고 깜짝 놀랐습니다." | 캡틴이 가장 놀란 순간 |
| ② 공감 | ~0:35 | "제미나이로 슬라이드 멋지게 만들었는데, 글자 하나 못 고쳐서 답답하셨죠?" / "생수 하나 사려 해도 최저가 비교하느라…" | 실전 예시 2개와 연결 |
| ③ 궁금증 풀기 | ~1:15 | **"AI 브라우저가 뭔가요?"** — 크롬 같은 인터넷 창인데, 안에 AI 비서가 앉아 있다. **로그인을 몰래 뚫는 게 아니라, 내가 이미 로그인해 둔 내 브라우저에서 나 대신 클릭·입력**한다. 비밀번호는 자동완성으로 채우고 AI는 비밀번호를 보지 않는다. (그림: 챗GPT = 말로만 알려주는 비서 / AI 브라우저 = 내 컴퓨터 앞에 앉아 직접 해주는 비서) | 수강생 최다 질문 |
| ④ 준비 | ~1:50 | 설치 빠르게: 홈페이지 → 내려받기 → 설치 → 로그인 + **쿠팡·구글에 미리 로그인해 두기** (③의 원리와 연결) | |
| ⑤-1 실전 | ~2:50 | **쿠팡 최저가 생수**: "쿠팡에서 2L 생수 중 가장 싼 거 찾아서 12개 장바구니에 담고 주문 화면까지 가줘" → AI가 검색·정렬·비교 → **결제 직전에 멈추고 물어봄** → 내가 확인하고 주문 | 캡틴 예시 (1) |
| ⑤-2 실전 | ~4:00 | **제미나이 노트북 슬라이드 → 수정 가능한 PPT**: 슬라이드 파일을 주고 "수정 가능한 pptx로 만들어줘" → 받은 PPT를 열어 제목 글자를 직접 고쳐 보이기 | 캡틴 예시 (2), ① 훅의 전체 과정 |
| ⑥ 안심 | ~4:25 | 안전 팁 2개: ① 결제·주문 버튼은 **반드시 내가** 누르기 ② 처음엔 로그인 필요 없는 일(검색·비교)부터 맡기기 | |
| ⑦ 마무리 | ~4:40 | "검색은 AI에게, 결정은 내가." 숙제: 이번 주 장보기 1개를 AI에게 맡겨 보기 + 다음 영상 예고 | |

마무리 한마디: 검색은 AI에게, 결정은 내가.
썸네일 문구:   PPT도 쿠팡도 AI가
