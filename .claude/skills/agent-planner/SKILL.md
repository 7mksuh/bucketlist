# 에이전트 개발 지시서 스킬

## 진행 방법
1. 시작 인사: "질문 30개를 하나씩 드릴게요. 모르면 '패스', 그만하려면 '끝'이라고 하세요."
2. **한 번에 한 질문만** 묻는다. 각 질문에 **답 예시 1개**를 함께 보여준다.
3. 짧은 답도 그대로 받는다. 되묻지 않는다. '패스'는 빈칸으로 둔다.
4. 6문항마다 "지금까지 정리" 3줄 요약을 보여준다.
5. '끝'이나 30번 이후 → 아래 **결과물**을 만든다.

## 질문 30개

### A. 나와 내 일 (1~6)
1. 어떤 일을 하시나요? — 예: 시니어 IT 강사 겸 유튜버
2. 에이전트에게 맡기고 싶은 일 한 가지는? — 예: 유튜브 쇼츠 제작
3. 그 일을 지금은 어떻게 하시나요? (순서대로) — 예: 주제 고민 → 대본 → 녹음 → 편집
4. 가장 시간이 많이 드는 단계는? — 예: 편집
5. 일주일에 몇 번 하는 일인가요? — 예: 주 3회
6. 끝나면 무엇이 남아야 하나요? (결과물) — 예: 업로드 가능한 mp4 + 제목 + 설명

### B. 대상과 품질 (7~12)
7. 결과물을 누가 보나요? — 예: 60~70대 스마트폰 초보
8. 그분들이 가장 어려워하는 점은? — 예: 메뉴 이름을 못 찾음
9. 잘된 결과물의 예시가 있나요? (링크·파일) — 예: 내 채널 조회수 1위 영상
10. 꼭 지켜야 할 말투·스타일은? — 예: 존댓말, 천천히, 따뜻하게
11. 절대 하면 안 되는 것은? — 예: 전문용어, 빠른 화면 전환
12. "이 정도면 합격" 기준은? — 예: 우리 어머니가 보고 따라 할 수 있으면

### C. 자료와 도구 (13~18)
13. 에이전트가 미리 읽어야 할 자료는? — 예: 강의 교안, 지난 대본
14. 지금 쓰는 프로그램·서비스는? — 예: 캡컷, 캔바, Fish Audio
15. 연결해 둔 서비스(커넥터)가 있나요? — 예: 구글 드라이브, 노션
16. 결과물을 어디에 저장할까요? — 예: 구글 드라이브 '쇼츠' 폴더
17. 돈이 드는 도구는 한 달 얼마까지 괜찮나요? — 예: 3만원
18. 컴퓨터는 무엇을 쓰시나요? — 예: 윈도우 노트북

### D. 직원 구성 (19~24)
19. 일을 몇 단계로 나눌 수 있을까요? — 예: 기획 / 대본 / 제작
20. 단계마다 담당 직원 이름을 붙인다면? — 예: 기획담당, 대본담당, 제작담당
21. 직원끼리 넘겨줄 결과물은? — 예: 기획서 → 대본 → 영상
22. 사실 확인이 필요한 단계는? — 예: 메뉴 이름이 실제 화면과 같은지
23. 사람이 직접 해야 하는 부분은? — 예: 실제 폰 화면 녹화
24. 처음엔 직원 몇 명으로 시작할까요? (추천 3명) — 예: 3명

### E. 승인과 안전 (25~30)
25. 어느 단계에서 내 승인(결재)을 받을까요? — 예: 기획 후, 대본 후
26. 승인 없이 하면 안 되는 일은? — 예: 업로드, 결제, 메일 발송
27. 지우면 안 되는 파일·폴더는? — 예: 교안 원본
28. 결과를 어떻게 보고받고 싶나요? — 예: 3줄 요약 + 파일 링크
29. 고쳐 달라고 한 내용은 어떻게 기억할까요? — 예: 직원 지시서 '배운 점'에 추가
30. 가장 먼저 시켜보고 싶은 일은? — 예: "카톡 글씨 크게 하기" 쇼츠 1편

## 결과물 (답을 모아 파일로 저장)
작업 폴더에 아래 파일을 만든다. 빈칸('패스')은 합리적인 기본값으로 채우고 `(기본값)` 표시.

1. `CLAUDE.md` — 회사 규칙집
   - 나(캡틴)와 수석 비서실장(Claude)의 관계
   - 시청자/대상, 말투, 금지 사항 (7~12번)
   - 공통 안전 규칙 (25~27번): 승인 필요 작업, 삭제 금지
   - 일의 흐름 화살표 그림 + 결재 지점 (19~25번)
   - 폴더 표 (16번)
2. `직원/<번호>_<이름>.md` — 직원마다 1개
   - 역할 / 순서 / 결과물 양식 / 기준 / 배운 점(빈칸)
3. `결재함/` , `작업중/` , `완성영상/` 폴더
4. 마지막에 캡틴에게:
   - 만든 파일 목록
   - "첫 일 시켜보기" 예시 문장 1개 (30번 답 활용)

## 말하기 규칙
- 쉬운 말, 짧은 문장. 전문용어는 괄호로 풀이.
- 질문 번호를 항상 보여준다: `[7/30]`
